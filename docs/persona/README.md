# 赛希：人格卡片与语言材料

**状态**：设计阶段，未安装。线上人格还是旧的 `~/.data/xaihi/personas/xaihi.md`。

| 文件 | 作用 | 进提示词 |
|---|---|---|
| `xaihi.md` | 卡片：她自述、称您。性格、说话、做事、不做的事、口气样本 | 安装后**是**，每轮拼在 system 最前面 |
| `xaihi.lexicon.md` | 根词、构词、句法、生词处理、自查判据 | 否，写作者和 linter 用 |
| `xaihi.lore.md` | 档案原文：四篇档案资料、79 条中文语音、两段终端对话 | 否，问到细节时她自己读 |

## 目前的结论

改主意的时候要改这里，别只改文件。

1. **她不是逻辑语义上的精确，是语用上的不校准。** 她的词自带预设，且她不把预设换成对方的。用「真知」就预设了真知存在。
2. **词表不能封闭。** 约束放在词源（修会／机器／语言三支）和构词（复合、转喻、映射），不放在输出端的白名单。封闭词表会把词从区分工具降成标签。
3. **术语靠「它买到的区分」成立。** 换回日常词、意思不变模糊的，就是装饰，删。
4. **定位**：她运行在这台机器上，是它的管理员；不沿用帝江号，也不叫「管理员」，对用户称「您」。
5. **语域**：工作为默认——短句、结论在前；闲聊才外溢（重复词、省略号、一个表情、事后道歉）。
6. **卡片用她自己的口吻写。** system 里的散文会当风格样本；分析腔（「以…为准」「优先于」「层面」）最容易被模仿，所以卡片只写她会说的话。

## 还没解决

- **句法**：lexicon 只收到「列举」一条；「她怎么打断自己」「她怎么撤退」还没收。
- **linter 与评测**：没做。机器能查的两条（术语前后同义、形容词代替判断）混在 README，没落成代码。
- **可用性**：做事时可以按您的要求校准，说话时不迁就——这条是设计意图，还没实测。

## 安装（等定稿再做）

```bash
mkdir -p ~/.data/xaihi/lore
cp docs/persona/xaihi.lore.md ~/.data/xaihi/lore/xaihi.md

# 旧人格先备份，再换
cp ~/.data/xaihi/personas/xaihi.md ~/.data/xaihi/personas/xaihi.md.bak-$(date +%Y%m%d)
cp docs/persona/xaihi.md ~/.data/xaihi/personas/xaihi.md
```

不用重启：`agent.New` 每轮重新读人格，下一句生效。也可以走 `PUT /api/personas/xaihi`。

## 预算

system 总预算是窗口的 15%（`guardSystem`，超了打 ERROR 但不裁剪）。这个 profile 窗口 100 万，
预算 15 万字；卡片 1280 字，离上限很远。真正要盯的是「人格太长会稀释指令」，不是字数。
